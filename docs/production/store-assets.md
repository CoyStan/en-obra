# Store Assets

## Generated Assets

- `assets/icon.png`: Expo app icon, 1024x1024, 8-bit RGBA PNG.
- `assets/adaptive-icon.png`: Android adaptive icon foreground, 1024x1024,
  8-bit RGBA PNG.
- `assets/splash.png`: splash image, 1242x2436, 8-bit RGBA PNG.
- `assets/favicon.png`: web favicon, 48x48, 8-bit RGBA PNG.
- `assets/store/icon-512.png`: Play listing icon candidate, 512x512,
  8-bit RGBA PNG.
- `assets/store/feature-graphic.png`: Play feature graphic candidate, 1024x500,
  8-bit RGBA PNG.

SVG sources live in `assets/source/**` so the raster files can be regenerated.

## Design Rationale

The mark uses a balance scale to signal fairness and clear shared accounting.
The palette follows the app UI: green for trust/actions, warm canvas for approachability,
gold for accent, and dark ink for legibility.

## Remaining Store Assets

- Final Play screenshots should be captured from Android or high-fidelity mobile
  viewport screens after human review.
- Store listing copy and category selection still need human approval.
- Feature graphic should be reviewed in Play Console preview before upload.
